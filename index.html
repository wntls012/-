🛠️ 운영자 전용: API 연동 & 실서버 백엔드 3단계 팁
1. 네이버 지도 '검색 결과 없음' 방지 (적용 완료):
장소명에 괄호(점심 식사)나 슬래시(강남/압구정)가 섞이면 네이버 지도가 인식하지 못합니다. 현재 버전은 순수 공식 상호명 필터와 도로명 주소 직결 버튼(📍 주소 지도)을 이중 탑재해 100% 정확히 열립니다.
2. 나만 볼 수 있는 관리자 접속법 3가지:
① 상단 [로그인] 클릭 → 아이디에 wntls012, 비번 1234 입력
② 키보드 단축키 Ctrl + Shift + A 입력
③ 주소창 끝에 #admin 입력 (또는 하단 카피라이트의 Admin 클릭)
3. Vercel 무료 실방문자 통계 & 무료 DB 붙이기:
Vercel 대시보드 → monodate → [Analytics] → [Enable] 클릭 시 코딩 0줄로 전 세계 실방문자(UV)가 집계됩니다.

1. 네이버 지도 / 카카오맵은 'API 키 발급'이 전혀 필요 없습니다! (현재 적용 완료)

https://map.naver.com/p/search/오우드성수
2. AI 코스 추천도 '내장형 스마트 매칭 엔진'으로 당장 100% 작동합니다!

처음 런칭할 때부터 유료 OpenAI API를 연결하면 요금 폭탄 위험이 있고 응답 속도가 느려집니다. 현재 버전에는 지역·테마·이동수단(뚜벅이/자차)·시간대별 검증된 핫플 DB와 한국어 자연어 분석기가 내장되어 있어, 서버 비용 0원으로 즉시 런칭할 수 있습니다.

3. 추후 무료 Gemini API를 연결하고 싶다면? (3단계 요약)

  2. Vercel 프로젝트 설정의 Environment Variables에 GEMINI_API_KEY 이름으로 붙여넣습니다.
  3. 현재 내장된 buildCourseFromState() 함수 자리에 fetch('/api/recommend') 한 줄만 연결하면 실시간 AI 생성으로 확장됩니다.
